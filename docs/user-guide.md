## 第一章：踏入修炼之途，账号与基础管理

私聊发送 `/start` 即可打开用户主菜单。

主菜单包含：`我的档案`、`每日修行`、`聚宝斋`、`药园`、`斗气`、`宗门`、`活动`、`求书中心`、`资产交易`、`账号服务`。

### 注册账户

入口：`账号服务 -> 注册账户`

可发送：

```text
注册账户
使用邀请码
邀请码
```

流程：

```text
1. 输入想要的用户名
2. 输入邀请码
3. 设置安全码 PIN
4. 设置 ABS 登录密码
```

用户名要求：3-20 位，只能包含字母、数字、下划线。进入注册前若本地档案暂时读取失败，Bot 会提示稍后重试，不会误当成未注册继续开户。注册成功后，Bot 会创建 ABS 账号，并绑定你的 Telegram ID。若开户或本地档案写入失败，Bot 会尽量退回邀请码；如果提示邀请码退回失败或需要管理员核查，请不要重复尝试同一邀请码，先联系管理员处理。

邀请注册默认获得 30 天有效期，具体以 Bot 提示为准。

### 个人邀请拉新

斗者初期及以上的正式账号，私聊发送以下任意命令可生成或查看个人邀请链接：

```text
我的邀请
邀请链接
拉新链接
邀请统计
```

新人通过邀请链接注册后获得 3 天体验权限；体验期内累计听书满 5 小时后，系统会自动为新人延长 3 天体验并分别私信提醒新人与邀请者，无需手动领取。邀请者每产生 1 名有效新人获得 10 积分，每月最多 150 积分；同一邀请链接每天最多激活 3 名新人体验。`邀请统计` 会展示累计激活、有效新人和本月奖励；统计暂时读取失败时会明确提示读取失败。新人体验账号不能生成邀请链接，需要先使用正式邀请码转正。

### 绑定已有账号

入口：`账号服务 -> 绑定账号`

可发送：

```text
绑定账号
绑定
```

流程：输入已有 ABS 用户名、输入 ABS 密码、设置安全码 PIN。进入绑定或校验既有绑定时若本地档案暂时读取失败，Bot 会提示稍后重试，不会误当成未绑定或首次接入。绑定后，Bot 会把你的 Telegram ID 与已有 ABS 账号关联。

### 使用续期卡

入口：`账号服务 -> 使用续期卡`

可发送：

```text
使用续期卡
续期卡
```

流程：发送续期卡密，Bot 校验卡密，校验成功后为账号续期。若账号已因到期暂停，续期后会自动尝试恢复 ABS 收听权限；如果提示恢复权限或本地状态同步异常，请联系管理员人工核查。积分兑换的邀请码、续期卡，以及经过交易行成交的卡密，仅限当前持有人使用、回收或再次上架；成交后归属转给买家。其他未登记归属、未经过交易行成交的卡密由持有码者使用。

### 获取线路

入口：`账号服务 -> 获取线路`

可发送：

```text
获取线路
线路
```

线路正文支持多行展示，Bot 会对 URL 和特殊字符做安全转义，避免消息格式错乱。线路配置暂时读取失败时会明确提示稍后再试，不会误显示为未配置。

用于获取当前 ABS 有声书服务器连接地址。

### 账号安全

入口：`账号服务 -> 账户安全`

可发送：

```text
修改密码
仅解绑不删号
解绑
删号注销
注销
```

说明：

- `修改密码`：需要先输入安全码，再输入新密码；若本地档案暂时读取失败，Bot 会提示稍后重新输入，不会继续校验空安全码或同步到空 ABS 账号。
- `仅解绑不删号`：需要安全码，只解除 Telegram 与账号绑定，不删除 ABS 账号；校验前若本地档案暂时读取失败，解绑不会执行。
- `删号注销`：高危操作，需要安全码和二次确认 `确认注销`。该操作会删除本地记录，并在满足条件时删除 ABS 账号；校验或确认时若本地档案暂时读取失败，注销不会执行；若删除过程中提示异常，请联系管理员处理。
- 特殊权限账号如无法自助注销，请联系服主处理。

## 第二章：我的档案，听书与每日修行

### 我的信息

入口：`我的档案 -> 我的信息`

可发送：`我的信息`

可查看：当前名称、Telegram 绑定 ID、当前积分、账号状态和到期时间、斗气境界、总计修为、闭关苦修时长、丹药药力、今日净修为、渡劫失败次数、体内丹毒沉淀。账号状态会同时检测本地档案、播放异常临停记录和 ABS 服务端状态；若状态不一致或暂时读取失败，会明确提示待核查或稍后重试，不会误显示为无资产或正常。若丹毒计数暂时读取失败，会显示读取失败；吞服确认前也会中止本次使用，避免误判剩余额度。

### 听书报告

入口：`我的档案 -> 听书报告` 或 `每日修行 -> 听书报告`

可发送：

```text
听书报告
报告
```

Bot 会读取 ABS 听书数据，生成个人听书报告，并同步斗气档案和境界。报告分别展示“累计实际听书”“今日实际听书”“净修炼时长”“今日净修为”，统一保留两位小数；累计实际听书优先采用 ABS 官方 `totalTime`，今日实际听书严格按北京时间当天统计。只有绑定有效 ABS 账号后才能使用；入口读取本地档案失败时会提示稍后重试，不会误当成幽灵钱包。听书时长以 ABS 官方日统计为总量基准；对于通过校验的跨日会话，在总量守恒的前提下按北京时间重新分配，不根据播放状态或播放进度额外估算时长。如果本地每日净修为累计暂时读取失败，Bot 不会把你的总净修为覆盖成 0，只会保留原档案值或提示稍后重试。

### 刷新今日净修为

入口：`每日修行 -> 刷新今日净修为`

可发送：`刷新我的今日净修为`

说明：按北京时间当天统计 ABS 听书记录，用于刷新今日宗门任务和个人档案中的净修为。刷新以 ABS 官方日统计为总量基准，并结合通过校验的跨日会话进行守恒分配；当天键缺失时按 0 记录，不根据活跃状态补算。该命令需私聊执行；若累计净修为读取失败，会提示稍后重试，不会覆盖既有斗气档案。

### 播放异常风控

处罚只采用已读取 ABS 会话中可证明属于当天的播放时长下界，不使用跨日比例估算或来源日中的不确定余额。巡检直接计算昨天、前天两个北京时间日期的会话下界，即使官方 `days` 暂无对应日期键，也不会丢弃已证明的时长。字段无效或未读取到的会话不作为处罚证据，因此可能少计。

系统每天按北京时间检查昨天和前天的实际播放时长，不使用天道压制后的净修为。统计读取或处理异常时，不执行本次提醒或暂停。

规则：

```text
单日可证明的播放时长下界 > 15 小时：Bot 私聊提醒一次
连续两个自然日可证明的播放时长下界均 > 15 小时：临时暂停 ABS 听书权限 24 小时
```

触发暂停时，Bot 会私聊说明异常日期、播放时长和预计恢复时间，并在公告群提示账号因播放异常暂停一天。本次风控不扣除积分、贡献、声望或修为。

暂停满 24 小时后后台自动恢复。若账号已到期、已被管理员封禁或绑定的 ABS ID 已变化，系统不会自动恢复，避免误解封。临停期间 `我的信息` 会显示播放异常临时暂停。

## 第三章：灵石财富与聚宝斋

### 积分兑换

入口：`资产交易 -> 积分兑换`

可发送：

```text
积分兑换
兑换
```

默认价格：

```text
邀请码：300 积分
30 天续期卡：150 积分
```

流程：Bot 显示当前积分和价格后，回复 `1` 兑换邀请码，回复 `2` 兑换 30 天续期卡，扣分后私聊发送卡密。续期卡兑换成功后，Bot 会询问是否现在直接使用；回复 `确认使用续期卡` 后会直接为当前正式账号延长有效期。邀请码兑换成功后，只有当前为新人体验账号或尚未注册 ABS 账号时才会询问是否直接使用；体验账号确认后会转为正式账号，未注册 ABS 账号确认后会进入开户注册流程并跳过再次输入邀请码；已有正式账号不会出现直接使用提示。实际价格以 Bot 当场提示为准；若价格配置暂时读取失败，Bot 会中止兑换，不会按默认价扣分。积分兑换的邀请码和续期卡均登记归属，只能由当前持有人使用、回收或上架；不可私下转赠给他人核销，交易行成交后归属转给买家。

### 卡密回收

入口：`资产交易 -> 卡密回收`，或私聊发送 `卡密回收` / `回收卡密`。

仅支持本服生成且当前真实可用的邀请码、续期卡。输入完整卡密后查看报价，再回复 `确认回收卡密`；成功后积分立即入账、卡密立即失效且不可撤销。回收价为当前配置定价的 60%；默认定价下邀请码为 180 积分，3/30/90/365 天续期卡分别为 9/90/270/1095 积分。

积分兑换的卡密和经过交易行成交的卡密，只允许当前持有人回收。报价和确认回收时都会复核归属；卖出后，原持有人不能再用该卡密或此前报价回收。其他未登记归属、未经过交易行成交的卡密由持有码者回收，请勿泄露明文；同一卡密最多成功一次。正在交易行出售的同一卡密会在成功回收时同步关闭。

## 第四章：药园，灵田与炼丹

入口：`药园`

药园需私聊使用；群聊只提示私聊。药园开放需要达到指定斗气境界，未满足条件时 Bot 会提示。

药园菜单：灵田管理、种子商店、草药背包、药铺回收、丹方炼丹。首页会显示灵田、成熟、种子、药草和已学丹方数量；某项暂时读取失败时会显示读取失败，不会用 0 代替。

### 灵田管理

灵田上限为 6 块，可查看灵田状态、开垦新灵田、种植、收获、一键收获成熟作物。

作物成熟后，Bot 会通过私聊提醒一次；如果同一时间有多块灵田成熟，会合并为一条提醒，并可点击提醒中的按钮进入灵田管理。

背包上架限制：物品名 1-40 个字，不能包含换行、制表符或其他控制/分隔字符；上架数量最多 1000；单价 1-100000 积分。适合丹药、灵草、种子等乾坤袋物品。背包上架会先锁定卖家库存，成交后自动转入买家乾坤袋。

上架成功后，Bot 会向群内同步一条交易行新货提醒，展示商品 ID、类型、名称、单价、库存、48 小时有效期、卡密来源标签和购买命令；背包丹药商品会在列表、详情、购买确认、购买成功、卖家成交通知和上架提醒中附带简要功效，自由卡密同名商品不显示系统丹药功效，卡密明文不会出现在群内。背包物品上架同样受 85% 底价约束，Bot 会按系统可识别的商城价、种子价、药草基础价或炼丹成本价判断。

交易行商品有效期为 48 小时。到期后 Bot 会自动下架；背包商品未售库存会退回卖家乾坤袋，自由卡密商品未售卡密不再出售。

若商品卖家数据出现不一致，系统会暂停该商品交易并通知管理员核查，不会继续自动下架、购买成交或错误退回库存。

### 购买商品

可发送：

```text
购买商品 商品ID
购买商品 商品ID 数量
```

数量不填默认为 1，单次购买数量最多 50。自由卡密商品成交后，Bot 私聊发送卡密；系统会在成交前复核邀请码/续期卡仍未使用，复核失败会中止交易并暂停商品待核查。购买本服邀请码或续期卡时，成交后卡密归属转给买家，买家之后可正常自用、回收或再次上架；旧持有人不能再核销、回收或出售该卡密。背包物品商品成交后，自动进入买家乾坤袋。高额订单会要求回复 `确认购买商品`。若库存状态暂时读取失败，列表/详情会显示读取失败，购买确认会中止并提示稍后重试。

### 卖家管理

可发送：

```text
我的交易行
下架商品 商品ID
交易行订单 商品ID
```

`我的交易行` 查看自己上架的商品、库存、已售数量、剩余有效期和下架命令。`下架商品 商品ID` 下架自己的在售商品。背包商品下架后，未售库存会退回乾坤袋；自由卡密商品下架后，未售卡密不再出售。`交易行订单 商品ID` 查看自己某个商品最近成交订单。

### 买家订单与举报

可发送：

```text
我的购买
我的订单
举报订单 订单ID [原因]
```

购买成功提示会显示订单号。`我的购买` 可查看最近购买记录和订单号，自由卡密可通过 `我的购买` 自助取回。背包物品订单显示已交付乾坤袋。举报无需填写原因；如主动附加原因，须为 3-200 个字，不能包含换行、制表符或控制字符。

### 手续费与限制

交易行手续费：

```text
成交额的 3%
最低 1 积分
不会吃掉单笔全部成交额
成交额为 1 积分时手续费为 0
```

关键限制：

```text
自由上架：需斗师境界及以上，单次最多 50 条卡密
卡密长度：每条最多 200 个字，且不能包含制表符或其他控制字符
商品名称：2-40 个字，不能包含换行、制表符或其他控制/分隔字符
背包物品名：1-40 个字，不能包含换行、制表符或其他控制/分隔字符
商品价格：1-100000 积分
背包上架数量：最多 1000
单次购买数量：最多 50
```

手续费会注入天道奖池。

## 白名单卡兑换

邀请码入口为「账号服务 → 使用邀请码」，用于新账号注册或体验账号转正；续期卡入口为「账号服务 → 使用续期卡」，按提示发送卡密即可续期。

白名单卡入口为「账号服务 → 兑换白名单」。也可私聊发送 `兑换白名单` 或 `使用白名单卡`，发送完整卡密后，回复 `确认兑换白名单`；发送 `取消` 退出。兑换后永久免除账号生命周期封禁和自动清理。卡密仅可使用一次，请勿泄露。

需要已有正式听书账号；体验账号请先用邀请码转正，未注册或未绑定账号请先完成注册或绑定。配置指定群组时须在群内。已经是白名单或超级管理员无需兑换，卡密不会被消耗。此前已经暂停的账号，兑换后请联系管理员恢复。


## 入群关注验证

管理员开启该功能后，尚未关注频道的新人入群会暂时禁言。请在 2 分钟内点击群提醒或 Bot 功能受限提示中的「去 Bot 验证」，进入 Bot 私聊并按提示启动 Bot，再点击「前往关注频道」。完成关注后回到 Bot 私聊，点击「我已关注，验证」。群内提醒和私聊面板会区分新入群、取消关注及业务补验，显示发出提示时的剩余秒数；重新打开面板会刷新剩余时间，不延长期限。验证仅限本人操作，转发链接不能替别人验证。成功后恢复原有群权限、删除群提醒并移除私聊验证按钮；如果原本已被管理员禁言，该限制继续保留。

未及时通过会被移出群，但可以重新加入，再完成新一轮验证。入群时已关注频道的用户直接通过；一旦进入验证流程，仅关注频道或打开 Bot 私聊不会放行，必须本人点击私聊验证按钮。取消关注后将重新禁言，并给予 2 分钟重新关注及完成私聊验证；即使已经重新关注，超时未点击验证仍会被移出群。使用 Bot 业务功能时会检查关注状态；发送 `/start` 可打开引导菜单。

出现“关注状态暂时无法确认”时，请稍后重试；网络异常不会被直接当作未关注。若管理员另行修改了你的群权限，该轮自动操作停止，请联系管理员处理。


## 频道公告和私聊抽奖

管理员启用公告频道后，抽奖、新书和重要服务信息集中发布在频道。抽奖及开放注册、维护恢复会在官方群发简短频道链接；如果官方群已设为该频道的关联讨论群，则使用 Telegram 自动同步的公告。新书和补偿说明只主动发频道，关联讨论群仍会收到 Telegram 自动同步。榜单、Boss、红包、互道等互动仍在群内。频道同步消息、频道身份消息及 Bot 消息不会触发个人入群验证或业务指令；请使用个人身份与 Bot 互动。

点击频道抽奖的「参与抽奖」后进入 Bot 私聊；首次使用需点击 Telegram 的 Start / 开始。Bot 展示奖品、积分消耗和开奖规则，点击「确认参与」后才扣分报名。重复确认不重复扣分，活动已结束或余额不足时不能参与。也可从抽奖列表选择活动，点击按钮参与。

开奖结果中的「领取奖励」会打开 Bot 私聊领取入口；领奖期限为开奖后 24 小时，密码、卡密和奖励领取明细不会公开到频道。活动入口会检查官方群资格及已启用的关注验证；公告频道配置本身不额外要求订阅其他频道。
